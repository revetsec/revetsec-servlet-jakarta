Revetsec helpers for applications on the jakarta.servlet API. They pass an HttpServletRequest to Revetsec core as raw input and write Revetsec results to an HttpServletResponse. They contain no protocol logic.

Revetsec core and the Servlet API are provided dependencies of this adapter: an application declares core, and its servlet container supplies the Servlet API. Adapter 1.x requires Revetsec core 1.0.0 or later. For the legacy javax.servlet API, use revetsec-servlet-javax.
